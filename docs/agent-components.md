# 健康助理怎样分工

[文档导航](README.md) · [English](en/agent-components.md)

同一名员工可以一边问主楼有哪些空床，一边等一组就诊文件整理完毕。两项工作使用独立进程。Pi 负责当前对话，DeerFlow 2.0 负责有明确资料范围的整理任务。机构提供的模型仍由院务服务调用和计量。

| 员工操作 | 谁负责 | 如何核对 |
| --- | --- | --- |
| 打字或按住说话问院况、找床位、定位到已筛选的页面 | 院务系统转写语音并限定可用工具。Pi 执行这次对话的工具循环，云端模型选择资料、组织回答。 | 看回答中的资料和页面按钮。打开表单和保存改动分别由员工操作。[Pi 运行入口](../platform_core/agents/pi_runtime.py) |
| 在聊天中要求整理就诊资料，按按钮上传文件 | 就诊上传按钮属于发起请求的员工。院务系统保存上传组编号，调用已配置的 OCR 和分类服务，员工确认类别、长辈、就诊日期及是否补充既有病例。 | 点击该条回答的上传按钮时，用量沿用这次对话的任务编号。直接上传另起一组。 |
| 资料选好后点击「开始识别并核对」 | 院务系统将原件和任务写入加密库再返回。DeerFlow 2.0 读取这位长辈这次就诊的授权文字，整理字段并检查引用。 | 在「健康助理 → 整理任务 → 核对草稿」按页核对原件。确认后由原有病例签认命令入档。关闭窗口可以继续聊天，重新登录后可找回本人待核对任务。[待办与恢复](../platform_core/visit_jobs.py) · [就诊字段与来源](../platform_core/visit_extraction.py) |
| 每日整理起居、三餐、活动，或查看近期健康变化 | 机构调度器选择在住对象、日期、床位和作业。生活简报和健康复核分别交给 DeerFlow 处理，分别使用经签认的生活事实和本人获准的健康摘录。 | 在档案中核对时间及来源编号，临床复核和家属推送沿用原来的授权条件。[机构巡查](rounds.md) |
| 员工纠正助理的表达或资料引用方式 | 院务系统把支持范围内的纠正转换为预定义、带版本的候选规则。员工用虚构中文案例对照前后结果，具有规则审批权的人员决定是否发布或回退。Pi 和 DeerFlow 仅在本次院区、岗位和业务类型适用时读取获准的规则。 | 在健康助理中打开「改进回答」，或从机构设置中进入规则管理。本项目借鉴 Hermes 的技能改进方法，并复用其 XLSX Skill；规则审批和回退由院务系统实现。[规则实现](../platform_core/agents/growth.py) · [技能及上游许可](../skills/UPSTREAM.md) |

## 交接、恢复和权限

Pi 的上传入口只负责把员工带到相应操作。上传接口在服务端检查会话和原对话。员工核对归属后，文档任务只接收该组原件。Pi 与 DeerFlow 共用院务权限服务和已批准的规则；各自的模型上下文按任务构建。后台进程拿到一项任务的资料投影，模型密钥和病例签认能力由宿主管理。

服务重启后，文档工作进程重新领取未完成的任务。原会话失效、人员权限变化或资料归属变化时暂停办理。原经办人重新登录、有权访问档案后，可从任务列表重新整理。重试之前核对已有的 OCR、模型回执和草稿；供应商回执不确定时沿用待对账机制。

## 部署和用量

Pi 使用锁定的 npm 依赖。DeerFlow 使用字节跳动官方 `v2.0.0`，源码固定到 `7e7f0410797693cf882594555ba414e0361d4c6f`。两者由院务服务通过私有管道驱动。Owner 可在「部署控制台 → 健康助理的执行组件」看安装情况，在「机构设置 → AI 用量 → 调用明细」点击任务编号，核对各步骤、输入、缓存命中、输出、OCR 页数和语音用量。历史调用沿用原计量记录，较早记录可能没有任务编号。[Pi 安装](quick-deploy.md) · [DeerFlow 安装与兼容模式](../deploy/deerflow/README.md) · [官方 2.0.0 发行说明](https://github.com/bytedance/deer-flow/releases/tag/v2.0.0)

## 一次任务会用多少 token

普通文字提问可以由一次模型调用直接回答。如果模型需要查台账，Pi 先让院务系统执行获准的查询，再根据结果组织答复。就诊资料整理把识别出的原文按行编号，DeerFlow 的模型只返回各字段对应的行号。OCR 按页单独计量，同一份已成功识别的原件可复用回执。定时健康复核发现同一天、同次入住的资料和规则均无变化时，跳过再次生成。

每次调用的 token 数取决于实际问句、授权摘录及输出长度。用量页把输入缓存命中、未命中和输出分列，OCR、ASR、朗读各用自己的单位。查成本时可按任务编号展开经办人的回执。[用量统计](provider.md)
