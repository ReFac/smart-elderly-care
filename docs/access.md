# 账号、授权与机构设置

首次启动后用账号 `owner` 登录。部署时可预先提供 `NH_OWNER_PASSWORD`。使用自动初始密码时，请从数据库所在目录的 `.owner-password` 文件读取，例如默认库对应 `.local/.owner-password`。Unix 上文件权限为 0600。环境变量只在创建首位业主时生效，更换已有账号密码请进入「账号与权限」。

## 岗位及可见范围

| 身份或模板 | 初始授权 | 可配置项 |
| --- | --- | --- |
| 总管理员 | 机构全部业务、账号、审计、界面和已购 AI 套餐用量 | 创建员工、调整授权、停用与恢复账号、重置密码、绑定经核实的亲属关系 |
| 院长 | 接待与档案、照护、仓储、财务、排班、报送、建议、设备模拟及授权业务日志 | 在员工详情勾选该院长的具体工作权限 |
| 护士 | 档案、照护、体征与用药、医疗图片读写、预警复核及语音申请确认 | 可独立收回预警复核、医疗图片写入或语音确认 |
| 护工 | 基本档案、照护和语音申请确认 | 可单独保留发起申请，将确认授权给值班人员 |
| 财务 / 自定义 | 财务与报送 / 从空权限开始分配 | 获授权的业务数据随角色一起生效 |
| 亲属 | 本人账号及明确绑定的长者姓名、本人可完善的资料 | 总管理员核验关系后创建，登录名与绑定长者不可在线改绑。更换授权对象时停用旧账号并新建绑定。 |

管理页面的岗位模板用于预填勾选项。服务端以实际勾选的权限做决定。医疗归档写入自动附带原件读取，语音确认同时要求目标照护权限，运营建议的可见性还需匹配来源业务域。工作台只下发当前账号可查看的集合和基本档案字段，未授权账号无法从快照读取管理配置、医疗原件或其他亲属资料。普通员工无法创建账号或修改自身授权。

操作日志按登录账号和变更发生时的房间信息记名。「操作日志」需有审计权限，员工还需有对应业务权限，总管理员可跨业务查询。历史日志缺少可验证的建议类别时，员工须同时拥有三类来源授权。

### 员工管理与个人中心

总管理员进入「账号与权限」，给指定员工勾选「在本人业务权限内管理员工账号」。该授权单独发放，已有院长与历史账号不会自动获得。受托人员只能查看和管理业务授权在本人范围内的普通员工，可以创建账号、调岗、启停及重设密码。受托人员的管理目录过滤其他管理员、本人、家属及超出范围的员工。启用院区权限解析时，服务端也会比较对应的机构、楼栋、楼层和房间。

管理人员可在编辑表单中预览未保存的岗位配置。只读接口 `POST /api/access/preview` 接收 `kind`、`role`、`permissions` 和可选的目标 `id`，返回服务端计算的模块和可办理操作。保存时再次检查双方授权。变更审计记录实际授予与收回的项目。

右上角姓名菜单与院内服务导航均可进入「个人中心」。每个人看到自己的账号、岗位、有效入口及授权。通过 `account.changePassword` 提交当前密码与新密码后，此账号所有设备都会退出。家属默认可以完善本人的亲属资料，总管理员按经核验的关系为该账号勾选「查看已完成的照护服务」后，才可查看其绑定长者最近 30 条已办服务，包括完成日期、计划日期、时间及服务名称。

### 班次交接

有照护权限的人员可查询 `GET /api/care/handover-recipients`。结果给出其他在岗照护账号的编号、姓名和登录名，用于区分同名员工。创建和签收均走带 `revision` 的业务命令接口。

| 命令 | 提交字段 | 服务端记录 |
| --- | --- | --- |
| `care.handover` | `assigneeId`、`note`，可选 `residentId` | 验证接班账号当前授权，保存提交人、接班人、时间及工单数量快照。交接双方都具有临床权限时，快照包含待复核体征数量，查看时按当前读者权限显示。 |
| `care.acceptHandover` | `handoverId`，可选 `note` | 已指定的接班人登录后可签收一次。保存实际签收账号、时间和备注。单人交班的创建及签收日志分别记录当时的房间。 |
| `care.withdrawHandover` | `handoverId`、`reason` | 原交班人填写原因后可撤回待签收记录。若同时发生签收与撤回，仅先成功的一方生效，回执与审计同事务保存。 |

照护人员可查阅交班台账。顶部待办只统计分配给本人且尚未签收的记录。历史版本仅填写姓名的交班条目保留为历史记录。

## 常见操作

1. 进入「账号与权限 → 新增员工」，填写姓名、登录名和初始密码。选岗位模板后复核勾选项，再保存。
2. 对已登录员工调整勾选项。每次读取或提交均重新取最新授权，前端重新载入即可同步导航。
3. 停用账号或重设密码会立即撤销该账号所有设备的会话。账号恢复后需要重新登录。总管理员修改自己的密码需要再输入当前密码。
4. 在「机构设置」更改平台名称、机构名称、主题及导航模块可见性。导航隐藏属于展示偏好，员工的真实访问权限仍由「账号与权限」决定。
5. 在「机构设置 → 平台 AI 套餐」查看本机构的套餐、到期日、额度和已用 token。平台运营方核实付款后开通。各机构账号均无填写凭据、换模型或发放额度的入口。具体操作见[平台套餐说明](provider.md)。

## 会话与验证

密码采用独立随机盐与 scrypt 派生，服务端使用 12 小时有效的不透明令牌，数据库只保存令牌摘要。使用浏览器的会话 Cookie 时，属性由 HTTP 入口设置。单个账号在 15 分钟内连续出现 8 次错误后暂时限制登录。注册过的账号独立计数，未知登录名共享失败预算。
