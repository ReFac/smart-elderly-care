# 电脑端业务目录

员工登录后从左栏进入业务。点击分组名称可以展开或折叠。右上角的「健康助理」也可以打开当前账号有权访问的页面和筛选结果。下表按 Owner 账号的显示顺序排列。

| 左栏一级入口 | 展开后的子项，按自上而下排列 | 对照依据 |
| --- | --- | --- |
| AI | 与健康助理对话，通过消息内的按钮打开表单或筛选后的页面 | 专用对话入口 |
| 首页 | 直接进入机构运营总览 | 画册显示一级入口 |
| 接待入住 | 接待管理、入住管理、退住记录、药品接收登记、请假管理、床位全景 | 入住管理及档案截图展开了此组 |
| 老人档案 | 直接进入长辈档案列表 | 档案截图显示此独立入口 |
| 照护服务 | 能力评估、安全风险评估、照护计划、复评安排、照护工作台、照护工单、定时工单与批量派发、健康体征、班次交接、用药管理、预警与确认 | 依据画册中的评估、计划与风险报告，以及本系统的照护流程编排 |

## 从目录进入一次业务

- **办理入住**　打开「接待入住 → 入住管理」，查找长辈档案，从对应行办理试住、入住或转床。在「床位全景」查看分配结果。
- **调整照护计划**　进入「照护服务 → 照护计划」，打开本人的计划页签调整项目、频次和执行人，保存后进入审核。风险评估报告在列表右侧打开。
- **办理补贴申报**　进入「费用管理 → 民政补贴申报材料」，按月份、楼栋或材料状态查询名单，查看欠缺的原件，勾选申报对象后生成清单。
- **找批量工单**　「照护服务 → 定时工单与批量派发」集中展示定时下发的工单。系统运行情况另在「系统监控 → 定时任务」查看。
- **返回上一个业务**　面包屑下面一行显示已打开的工作页签。工作区最多保留 10 个页签（含固定的首页），新开时优先收起最久未使用且未固定、无未保存修改的页签。选中页签后可点击图钉固定，「管理页签」可取消固定或关闭。点击页签切换，点 × 关闭，点右端「刷新」重新读取当前页。「业务视图」可切换同一模块的其他功能，例如机构设置中的备份与恢复。

目录按权限裁剪。家属和注册访客使用与其身份对应的个人入口。菜单与路由定义位于 [desk-navigation.js](../web/lib/desk-navigation.js)，[桌面浏览器回归](../tests/browser/desktop_workspace.py) 和[角色回归](../tests/browser/workspace_roles.py) 验证实际入口与权限。
