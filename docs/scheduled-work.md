# 定时工单

在「照护业务 → 照护服务 → 定时工单」新建伙食、巡查或照护计划。Owner 可管理全机构。院长、护士长和另获定时工单权限的员工按工作区域管理。照护和临床人员可看到本岗位有权处理的定时待办。

- **时间与名单。** 选择执行时刻、每周执行日、开始和结束日期。可选择全部授权区域、指定分院、指定房间或点名长者。派发时按当天在住、床位及离院记录核对成员。可指定员工、照护岗位或当班照护组。
- **派发与改期。** 服务按上海时间检查。服务停机后在当天恢复时补发，重复检查不会生成第二批。暂停后停止后续派发。已派发批次保留实际名单和时间。今天临时换菜时用「当天餐单」，已签认的进食记录保留当时版本。
- **伙食签认。** 工单附当餐菜单。照护人员可在今日批次或个人工单中点击「核对今日伙食」，也可向健康助理说「其他老人都吃了今天午餐，101 房 02 床的老人没有吃青菜」。先核对餐次和人员，再确认实际进食的菜品。漏吃的菜写入该长者的生活时间线，并与这次工单的实际签认人关联。出现多个可能批次时，先选择正确批次。
- **既有自动提醒。** 巡查简报、照护计划复评、到时用药、随访、集体活动签认、试住、续住和财务到期等均可在此查看当前待办和相应管理入口。加密备份和归档保管到期在维护区查看。
