# 定时工单

[文档导航](README.md)

在「照护业务 → 照护服务 → 定时工单」新建伙食、巡查或照护计划。Owner 可管理全机构的计划。院长、护士长和其他获授权员工管理各自工作区域的计划。照护和临床人员登录后可见本岗位有权处理的待办。

- **时间与名单。** 先选每周哪几天执行、几点执行，以及计划的起止日期。计划可以覆盖全部授权区域，也可以指定分院、房间或具体长辈。执行人可以是指定员工、照护岗位或当班照护组。派发前，系统根据当天的在住、床位和离院记录核对名单。
- **派发与改期。** 系统按上海时间派发工单。同一计划一天只派发一次，如果停机后当天恢复，会补发当天漏掉的批次。暂停计划后，已派批次仍保留当时的人员名单和派发时间，后续批次停止派发。
- **每周菜单。** 早餐、午餐和晚餐各自设置周一到周日的菜品。遇到临时换菜时用「当天餐单」设置指定日期。派发时先查当天是否临时换菜。当天没有单独设置，就用该星期几的菜单。两处都没设置才使用默认菜品。临时更改会更新尚未签认的工单，已签认的进食记录保留当时菜单。
- **伙食签认。** 照护人员可从「今日派发 → 查看伙食批次」或个人工单核对餐次、人员和实际吃过的菜，也可向健康助理口述。长辈没吃哪道菜，会连同签认人记在其生活时间线里。签认后，点击批次内的长辈姓名，即可在档案里看到这顿饭的记录。
- **既有自动提醒。** 巡查简报、照护计划复评、到时用药、随访、集体活动签认、试住、续住和财务到期等事项的待办都列在这里。点击相应入口可继续办理。要查加密备份或已经到保管期限的归档，请打开维护区。
