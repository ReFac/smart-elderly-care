# 定时工单

在「照护业务 → 照护服务 → 定时工单」新建伙食、巡查或照护计划。Owner 可管理全机构。院长、护士长和另获定时工单权限的员工按工作区域管理。照护和临床人员可看到本岗位有权处理的定时待办。

- **时间与名单。** 选择执行时刻、每周执行日、开始和结束日期。可选择全部授权区域、指定分院、指定房间或点名长辈。派发时按当天在住、床位及离院记录核对成员。可指定员工、照护岗位或当班照护组。
- **派发与改期。** 服务按上海时间检查。停机后在当天恢复时补发，同一计划同一天只派发一次。暂停后停止后续派发。已派发批次保留实际名单和时间。
- **每周菜单。** 早餐、午餐和晚餐各自设置周一到周日的菜品。遇到临时换菜时用「当天餐单」设置指定日期。派发优先采用指定日期餐单，其次采用该星期的菜单，最后采用默认菜品。临时更改会更新尚未签认的工单，已签认的进食记录保留当时菜单。
- **伙食签认。** 照护人员可从「今日派发 → 查看伙食批次」或个人工单核对餐次、人员和实际吃过的菜，也可向健康助理口述。漏吃的菜写入该长辈的生活时间线，并与签认人关联。签认后点击批次内的长辈姓名，档案会定位到这顿饭的记录。
- **既有自动提醒。** 巡查简报、照护计划复评、到时用药、随访、集体活动签认、试住、续住和财务到期等均可在此查看当前待办和相应管理入口。加密备份和归档保管到期在维护区查看。
