# 院内评估、随访、用药与转介验收

以下流程可在独立的演示数据库用虚构长者复验。业务日期和医嘱计划时刻均按上海时区解释。每次提交由服务器核实登录人员和当前数据版本，操作日志可按经办人或房间回查。

## 标准量表和个体计划

1. 具有照护权限且另具临床或医疗档案查阅权限的账号进入「能力评估 → 评估记录 → 标准量表评估」。先选长者和实际评估日期，登记两名同时参与评估的人员，其中一人具有医护专业背景。纸质录入还须填写可追溯的原表编号。
2. 按原表录入四个维度共 26 个观察项目。界面提供评分细则原文，服务端核对量表版本、项目全集、每项分数范围和两位评估人员。总分由服务端汇总。经办人员选定等级调整条件时，须填写已核实的凭据。正式评估由合资格的评估机构组织，另按规范保存两名评估人员及信息提供者签字的报告。系统保存院内计分、录入人及纸质原表编号，专业资质和签署原件由机构核验归档。[GB/T 42195-2022 国家标准登记](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=D8A0B4F27794EC73C511F1B948103256)，[标准全文，表 2 至表 6 及第 5 章](https://www.zhuhai.gov.cn/smzj/attachment/0/385/385975/3719486.pdf)
3. 分别核对能力等级、院内核定的照护等级和复评日期。保存后检查原表来源、日期、总分和四个分项。点开「逐项评分」可核查输入。普通照护观察沿用原来的「登记评估」入口。
4. 进入「照护计划」查看当前草稿。需协助的观察及分数未满的维度进入待核对的支持项目；责任人可人工指定，留空时按同照护区当日排班及待办量匹配。具照护权限的复核人确认后才派发工单，并固化原照护等级、生效等级和批准日期。「复评安排」和后续工单保留预约日期。补录早于现有评估的旧量表，保存历史记录及原始日期，现行计划继续执行。

## 院内筛查和随访

在「照护服务 → 筛查与随访」或长者档案中登记筛查项目、现场观察。临床人员分级时填写判断依据、责任人、干预安排及预约日期，可引用同一位长者的评估。到期后，从「待处理事项 → 到期随访」打开台账，登记实际干预和效果。核对原观察、分级人、跟进责任人及办结人。已经办结的记录保留在档案中。

## 医嘱核查和定时提醒

1. 临床人员按已有医嘱登记单次执行安排，填写药品名称、医嘱原文、负责人和计划时刻。时间留空的医嘱进入人工复核台账。通过复核且已设置计划时刻的医嘱出现在「用药管理 → 定时提醒」，工作台打开时按上海时刻标出已到时记录。护士给药后登记执行，凭证保留计划时间、实际登记时间、复核人、执行人和补充说明。
2. 护理部门以**已获机构专业核准**的资料维护配伍规则。由总管理员为经核定的岗位分配临床和用药规则维护两项权限。维护人在「配伍规则」录入两个药品通用名、提醒、版本和核准资料编号。旧版须先停用并填写原因，之后可发布另一版本。一般临床人员可以查看规则、复核医嘱。
3. 核查作用于同一位长者待复核和待执行的医嘱组合，按登记名规范化后精确匹配。过敏记录和同名待处理医嘱另行提示。存在提醒时必须写明人工核查结论。新增医嘱或生效规则产生新提醒时，已复核的相关医嘱重新进入待复核。已保存的每次复核保留当时的规则、依据及结论。用药史、院外医嘱、别名和剂量等情况须由医护人员结合原始资料判断。医嘱录入和计分均不消耗模型额度。

## 院外衔接与数据包

在「长者档案 → 院外衔接」登记接收机构、渠道、交接类型和摘要，可选择同一档案中的评估。渠道包括医联体、基层公卫、长护险经办和其他机构。退住后仍可从原档案进入。交接时保存当时的过敏与风险记录；后续档案修改与历史交接分别留痕。

1. 临床经办人在「查看交接 → 登记本人授权」记录本人同意的共享范围及凭据编号。每笔授权对应这次交接、指定机构与范围，支持撤回并保留授权记录。授权凭据由机构核验。
2. 在有效授权期间点击「导出交接数据包」，核对机构和范围后下载 UTF-8 JSON。每次生成保留导出编号、经办人、日期、所引用的授权序号以及生成时的内容。撤回后停止新的授权导出。打印件、已交付文件或第三方系统的回收需由实际接收方配合。
3. 接到接收方回执后，填入接收人及纸质回执编号或人工核实记录。台账随即显示「已登记回执」，保留本院登记人和日期。

| 本地字段 | 交接含义 | 对接时需约定 |
| --- | --- | --- |
| `version`、`referralId`、`exportId` | 包格式、院内交接号、单次导出凭证号 | 对方外部流水号、幂等键和回执关联 |
| `residentName` | 本次被授权共享的长者姓名 | 接收方采用的身份核验方式，同名长者需另行核对 |
| `channel`、`destination` | 协作渠道、具名接收机构 | 接收机构代码、实际接口地址和授权范围 |
| `handoff`、`summary`、`date` | 交接类型、人工确认摘要和交接日期 | 当地业务类型代码、摘要格式和日期格式 |
| `consentScope` | 本次生成时有效的共享范围 | 对方授权协议及撤回处理 |
| `allergies`、`risk` | 仅在授权包含过敏与风险记录时输出 | 本地自由文本和接收方编码的核验方法 |

真实医联体、公卫及长护险系统上线前需要各接收单位提供字段字典、鉴权、测试回执和验收环境。目前院内可核实的结果是本地 JSON、生成凭证和人工登记的回执。纸质授权凭据编号、亲属身份证及医疗原图均不进入此包。
