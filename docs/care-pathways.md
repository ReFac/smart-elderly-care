# 院内评估、随访、用药与转介验收

[文档导航](README.md)

请在独立的演示库中选用虚构长辈，按以下步骤验收。业务日期和医嘱的计划时间均按上海时区计算。每次提交时，服务器都会核实经办人的登录身份和当前数据版本。要回查某次办理，可按经办人或房间检索操作日志。

## 标准量表和个体计划

1. 用有照护权限的账号登录。该账号还须具有临床权限或医疗档案查阅权限。进入「能力评估 → 评估记录 → 标准量表评估」。先选长辈和实际评估日期，登记两名同时参与评估的人员，其中一人具有医护专业背景。纸质录入还须填写可追溯的原表编号。
2. 按原表录入四个维度共 26 个观察项目。界面提供评分细则原文，服务端核对量表版本、观察项目是否齐全、各项分数是否在范围内，以及两名评估人员的信息，再计算总分。经办人员选定等级调整条件时，须填写已核实的凭据。正式评估由合资格的评估机构组织，另按规范保存两名评估人员及信息提供者签字的报告。系统保存院内计分、录入人及纸质原表编号，专业资质和签署原件由机构核验归档。[GB/T 42195-2022 国家标准登记](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=D8A0B4F27794EC73C511F1B948103256)，[标准全文，表 2 至表 6 及第 5 章](https://www.zhuhai.gov.cn/smzj/attachment/0/385/385975/3719486.pdf)
3. 分别核对能力等级、院内核定的照护等级和复评日期。保存后检查原表来源、日期、总分和四个分项。点开「逐项评分」可核查输入。普通照护观察沿用原来的「登记评估」入口。
4. 进入「照护计划」查看当前草稿。如果观察结果显示长辈需要协助，或某个维度未得满分，对应的支持项目会列入草稿，等待核对。可手动指定责任人。留空时，系统按同一照护区当天的排班和待办量匹配。具照护权限的复核人确认后才派发工单，同时记下调整前的等级、生效的等级和批准日期。「复评安排」和后续工单保留预约日期。补录早于现有评估的旧量表，保存历史记录及原始日期，现行计划继续执行。

## 院内筛查和随访

在「照护服务 → 筛查与随访」或长辈档案中登记筛查项目、现场观察。临床人员分级时填写判断依据、责任人、干预安排及预约日期，可引用同一位长辈的评估。到期后，从「待处理事项 → 到期随访」打开台账，记录实际做了哪些干预、效果如何，再核对最初的观察记录、分级人、跟进责任人和办结人。已经办结的记录保留在档案中。

## 医嘱核查和定时提醒

1. 临床人员按已有医嘱登记单次执行安排，填写药品名称、医嘱原文、负责人和计划时刻。时间留空的医嘱进入人工复核台账。通过复核且已设置计划时刻的医嘱出现在「用药管理 → 定时提醒」，工作台打开时按上海时刻标出已到时记录。护士给药后登记执行，凭证保留计划时间、实际登记时间、复核人、执行人和补充说明。
2. 护理部门以**已获机构专业核准**的资料维护配伍规则。由总管理员为经核定的岗位分配临床和用药规则维护两项权限。维护人在「配伍规则」录入两个药品通用名、提醒、版本和核准资料编号。旧版须先停用并填写原因，之后可发布另一版本。一般临床人员可以查看规则、复核医嘱。
3. 系统核查同一位长辈待复核、待执行的医嘱组合，先统一登记药名的格式，再精确匹配配伍规则。过敏记录和同名待处理医嘱另行提示。存在提醒时必须写明人工核查结论。新增医嘱或生效规则产生新提醒时，已复核的相关医嘱重新进入待复核。已保存的每次复核保留当时的规则、依据及结论。用药史、院外医嘱、别名和剂量等情况须由医护人员结合原始资料判断。医嘱录入和计分均不消耗模型额度。

## 院外衔接与数据包

在「入住管理 → 院外衔接」登记接收机构、渠道、交接类型和摘要，可选择同一档案中的评估。渠道包括医联体、基层公卫、长护险经办和其他机构。退住后仍可从原档案进入。交接时保存一份当时的过敏和风险记录。之后再修改档案，改动和原交接记录分别留存。

1. 临床经办人在「查看交接 → 登记本人授权」记录本人同意的共享范围及凭据编号。每笔授权对应这次交接、指定机构与范围，支持撤回并保留授权记录。授权凭据由机构核验。
2. 在有效授权期间点击「导出交接数据包」，核对机构和范围后下载加密的 `.akdoc`。收件人须登录本机构工作台，通过「院外衔接 → 打开加密文件」查阅，并具备当前分院及临床权限。系统保留导出编号、经办人、日期、授权序号和当时的内容。一旦撤回授权，平台也会停止打开已经交付的加密文件。重新取得同意后，须生成新的授权包。已人工转录或打印的资料由实际接收方管理。
3. 接到接收方回执后，填入接收人及纸质回执编号或人工核实记录。台账随即显示「已登记回执」，保留本院登记人和日期。

| 本地字段 | 交接含义 | 对接时需约定 |
| --- | --- | --- |
| `version`、`referralId`、`exportId` | 包格式、院内交接号、单次导出凭证号 | 对方外部流水号、幂等键和回执关联 |
| `residentName` | 本次被授权共享的长辈姓名 | 接收方采用的身份核验方式，同名长辈需另行核对 |
| `channel`、`destination` | 协作渠道、具名接收机构 | 接收机构代码、实际接口地址和授权范围 |
| `handoff`、`summary`、`date` | 交接类型、人工确认摘要和交接日期 | 当地业务类型代码、摘要格式和日期格式 |
| `consentScope` | 本次生成时有效的共享范围 | 对方授权协议及撤回处理 |
| `allergies`、`risk` | 仅在授权包含过敏与风险记录时输出 | 本地自由文本和接收方编码的核验方法 |

对接医联体、公卫或长护险系统前，请向相应接收单位索取字段字典、鉴权方式、测试回执和验收环境。目前可在院内核验加密交接包、生成凭证及人工登记的接收回执。纸质授权凭据编号、亲属身份证及医疗原图均不进入此包。

## 可重复检查

运行以下命令覆盖计分边界、资料缺失、历史纸表、照护等级生效、随访状态、跨长辈关联、授权范围及撤回、专业规则换版及已登录会话的撤权。测试使用虚构数据。

```bash
python3 tests/run.py -p test_pdf_care.py -v
```

电脑端再用接待账号点楼层平面图或房号，选目标房间的空床，办理新入住或将已在住长辈转入。新入住表单预选目标床，转床确认显示目标床号。转床后核对原床是否释放、目标床是否已占用，再查看长辈原档案和操作日志中的变动。只有查看权限的账号可核对床态。
