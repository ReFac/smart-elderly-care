## 从哪里开始

在部署方提供的机构网址打开官网。访客可以打开「环境导览」和「常见问题」。登录后这两个入口也列在系统管理中。员工点登录进入电脑工作台，工作台路径为 `/?workspace=1`，本机默认服务地址为 `http://localhost:8765`。外地设备使用机构发布的地址。首次安装的 Owner 在服务端初始化口令；演示环境的账号由演示部署方提供。

| 我现在要做什么 | 从哪里开始 | 完成后在哪里核实 |
| --- | --- | --- |
| 前台接待有意来访的人 | 接待入住 → 接待管理 → 手工登记 | 客户跟进、接待时间表 |
| 给新来的人建立一份完整档案 | 左栏机构名下的「新建长辈档案」，或首页的同名入口 | 入住管理的待入住名册 |
| 护工接班、做三餐和巡房 | 照护服务 → 班次交接、定时工单与批量派发；左栏「照护工单」 | 已完成服务、长辈生活时间线、交班签收 |
| 护士复核异常或过往就诊 | 照护服务 → 健康体征、预警与确认；长辈档案 → 医疗资料 | 异常处置凭证、已签认病例或专项评估报告 |
| 财务查到账、欠费、退款 | 费用管理 → 财务总览、待收费、收费记录 | 对应长辈账单明细、实收流水、退款对账 |
| Owner 设置人员、备份和服务 | 系统管理 → 账号与权限、机构设置；系统监控 | 操作日志、最近改动、已核验的恢复点 |
| 想知道某项业务在哪 | 右上角「健康助理」或左栏「AI」，输入业务目标并点击答复中的按钮 | 打开的业务页、筛选条件及当前账号可办理的操作 |

每个账号看到的栏目取决于岗位、院区及其他授权。工作页上方有面包屑与页签；「业务视图」可切到同一模块内的明细台账。图钉可固定页签，已固定项有独立高亮。最多同时保留十个，含首页；达到上限时，最久未用的未固定、无未保存修改的页签可被收起。若全部受保护，先关闭一个可关闭页签。点击长辈姓名按房号核对本人，进入详情后再办理；同名员工也可按岗位、账号和分院区分。关键业务会显示「确认改动」，在这里核对对象、金额或状态、填写说明，然后确认。发生版本冲突时，重新读取相关行，查现有凭证，再决定是否重新办理。[完整导航](desktop-navigation.md)

## 访客、意向登记与排期

1. **看院环境。** 公开入口为 `/visit` 和 `/roomtour`。访客可以浏览场景及热点，停留后的回电邀请可关闭。主动预约或同意回电时才提供联系方式。微信小程序须由访客点击授权，部署方完成微信配置后才能换取号码；失败时可手填。普通访客也可只用用户名、密码注册。公开 FAQ 位于 `/faq`。[客户端与 Roomtour](clients.md)
2. **接待管理。** 前台在「客户跟进」查看来源、姓名或新客标记、既有联系人关系和历次沟通。来电或直接来访用「手工登记」录入时间、号码、意向与反馈。主动申报或人工登记可以使用已有号码。对待回访人员先拨电话，再登记接通情况和真实反馈；现有入住关系、拒绝回访等会影响待回访名单。
3. **接待时间表。** 选分院、日期、来访或回访、起始时间和时长，经电话确认预约后选接待席位。每半小时一个单位，一次预约全程占同一席。总容量尚有余量而约不成时，检查是否存在全程空闲的同一席。可改期、取消，查看当日来电时刻。接待后登记结果；已结束跟进的客户在「归档记录」按最近 365 天查阅。[意向与预约规则](facility.md)

## 入住、床位与档案

| 操作 | 输入和核对 | 结果与例外 |
| --- | --- | --- |
| 建档 | 打开「新建长辈档案」。填写姓名，核对性别、生日或登记年龄、本人手机号、分院和类别。展开语言、婚姻与职业，按区划选择出生地、籍贯和现住址。有权限时展开家庭成员、配偶、每一位子女、联系用途、已拨通日期、经济支持及养老金；临床经办人可手工签认首次健康摘要。 | 一次确认同时保存所有已填资料，新档案状态为待入住。核对同名历史档案号；旧住期与新住期分别留存。归档类别需核对原退住日期。 |
| 试住、转正 | 在「入住管理」目标行右侧点「办理试住」，核对起止日、床位与一次性收费；行内「试住」查看约定，「办理入住」办理转正。Owner 可在「机构设置 → 试住约定」设默认值，初始为 3 天 2 夜。 | 床位标注「试住中」，名册保留待办直至确认或取消。最后一天结束后释放试住床；未登记决定会生成提醒。未转正按回访任务记录联系对象、原因、反馈及下一步。 |
| 正式入住、续住 | 搜索既有档案，选择空床、入住日期、月付账单日、合同与收费明细；无期限合同可保持默认。核对首期收费、押金及收款方式。有财务权限方可确认相关收款或欠费安排。 | 有效预缴抵扣、已核实的收款或明确批准的临时欠费依表单执行；普通建档不会占床。账单日默认取入住日，短月取月末，下月按约定日。固定期限按符合条件的月费结清延续，查看续住记录。 |
| 换床、请假、退住 | 按姓名中的任一字、房号搜索。可从床位台账或楼层图点房间、空床。确认原床、新院区/楼栋/床号。前台用「请假管理」录起止和事由，退住时核对床位、日期和小结。 | 换床会释放原床，历史护理仍关联原执行位置。请假保床，退住后床位释放。「退住记录」和归档档案可查；欠费或退款另在财务结算。 |
| 核对或打印 | 名册可按状态、楼栋等筛选。行内查看简档或点标题栏的详细档案，打印床头卡、档案或页面提供的报告。 | 每次分床的床头卡关联当次床位。扫码后依当前登录权限核对，转床后的旧卡需换印。正式机构退住满一年进入保管复核，保留档案及身份关联。演示库到期清理模拟日常资料。[保管与病案验收](medical-commercial.md) |

**床位管理与扩建。**「全部床位」「楼层平面图」「房间看板」「床位台账」显示同一批实际床位。先选分院和建筑，再选楼层；可以点图上热点，也能点房号。支持按楼层房号、房间、区域或图上位置排序。管理员可建分院、扩楼层房间、设置单/双/多人间并维护平面布局，变更前核对受影响床位，已占用床的冲突需先按业务办理。「区域设置」按楼栋建立父子区域，将楼层或房间归入区域，给员工分配一个或多个职责区域。实际可读范围由账号授权控制。经营看板、库存或费用页若显示不同数量，先核实其院区、日期、分母。[分院、房间与入住](facility.md)

**长辈档案的三部分。**

- 「登记资料」查看本人基础信息、联系用途、家庭和经济资料、亲属代录和证件版本。收费、费用来源与本人养老金各有入口。证件可保存本人身份证正反面、户口本等原件。原件缺项在档案或民政补贴材料表处理。授权不足时，「申请编辑权限」可指定长辈与原因；具备资格的审批人在「预警与确认 → 权限申请」核对范围、用账号实名签认。获批员工仅在有效期和该档案内使用。
- 「医疗资料」核对慢性病标记、确诊依据、过敏、用药、自报和评估。每次就诊建立独立记录，医疗文书和后续补件归入该次就诊。可手填既往用药、本次处方、医嘱、机构、复诊，或由有权员工通过健康助理上传原件。用姓名或房号选人，选已有就诊或填新就诊日期，核对 OCR 的医院、页码和原文，再签认。原影像可归档；影像结论须有书面依据。查看「医疗评价」时可在报告、逐项详情和其他评估间切换，再打印报告。[字段与病例](dossier.md)
- 「疗养院时间线」按日期查看实际就餐、护理执行和房间；点击事件可回看凭证。有权员工可手填健康简介，或核对基于这位长辈已有病历等授权资料生成的草稿。「近期变化与建议」可手动生成或依巡查设置生成；缺乏观测时，查原始记录、补录事实，勿把空白当作健康结论。档案中的「最近改动」保持当前长辈筛选。[日常记录与合并](care-timeline.md) · [巡查简报](rounds.md)

## 护工、护士与临床岗位

| 在哪里办 | 怎样办 | 在哪里看结果 |
| --- | --- | --- |
| 照护服务 → 能力评估、安全风险评估 | 选择长辈、量表、评估日期、两位实际评估人；纸表录入填写原表编号。按实际观察填项，登记有依据的调整和复评日。专项风险报告按相应项目填写观察和评分依据。 | 评估记录、等级判定、风险报告中的分项、重点和下次计划；过往记录保留。选择最新日期再核对当前有效方案。 |
| 照护计划、复评安排 | 根据评估草稿核对服务包和计划项目，可改频次、执行岗位、人员和启用状态。核对负责对象和生效日期，再由有权员工审核派发。 | 已批准的计划和相应工单；编辑生效计划须重新审核。到期复评从提示回到原长辈。 |
| 照护工作台、照护工单 | 选择待执行任务，核实长辈和床位，登记执行时间、备注或签认；按需扫码。完成服务可抽检，查看签认人、执行时床位和关联记录。 | 「已完成服务」、长辈或房间时间线。饮水、普通用餐等可按长辈/房间设置合并展示，展开仍有逐笔证据。异常、巡视与用药分开保留。 |
| 定时工单与批量派发 | 新建伙食、巡查或照护计划。设起止、星期、时刻、分院/房间/点名名单、执行人员或班组。菜单按星期设，特定日期用「当天餐单」覆盖。 | 「今日派发」打开实际批次，核对派发人数和工单。在演示库可看三餐及早晚巡查。暂停只影响后续派发；同日重跑防重复，当天停机重启可补发。 |
| 伙食与集体活动 | 打开伙食批次或「集体活动」。核对实际日期、原菜单和名单，移除未到者，按人取消没吃的菜、记实际份量。授权人员确认。 | 点批次内姓名直接看这顿吃了什么。已签认餐次保留当时菜单，「当天餐单」只更新尚待签认的工单。 |
| 健康体征、筛查与随访 | 录长辈、体征、数值、单位和异常观察；对待复核项核实并写处置。筛查可记观察、级别依据、责任人、预约日期，回访后写实际效果。 | 体征凭证、到期随访、办结记录。未核实的设备或声音观察先分清房间和个人归属。 |
| 班次交接、人员排班 | 排班人员选择分院、员工、日期和班次；周视图和全部排班台账核对安排。交班人登记事项，指定接班人，核对交班范围；接班人用本人账号签收。 | 交接台账区分待签收和已签收，记录交、接人及时刻。账号、班次或区域不符时核对排班。 |
| 院外衔接 | 登记接收单位、渠道、交接内容，可引用同一档案的评估；登记本人授权范围与凭据后导出加密交接包。收到真实回执后录入接收人、凭据号。 | 交接台账保留授权、撤回、导出和人工回执。当地 HIS、公卫和经办系统自动收件需另行联调。 |

**药品接收与执行。** 在「接待入住 → 药品接收登记」按档案登记实际交来的药品和数量。「用药管理」里按已有医嘱录药品、执行说明、负责人和时间，人工复核后才执行。核查过敏、待执行的同名药和已核准的配伍规则，有提醒时写人工结论。可从「定时提醒」「筛查提醒」回查；有权人员在「配伍规则」按核准来源登记、停用及换版。长辈体检自报的药品需核对联网候选或人工更正，自报与临床医嘱分别保留。

**床旁服药。** 房间页点「核对本房服药」，或在健康助理口述已喂药房间、床位、时段和例外。逐人逐时段核实，实际未服要写原因，可暂跳过。「今日无需服药」作为经办人报告供护士复核。只有相应权限者可另行勾选已核准的到时医嘱。签认后查档案的服药核对凭证。[床旁核对与床头卡](medication-rounds.md)

**预警与确认。** 设备预警先看来源、房间、观察证据，到场核查后选择核实或误报，填写处置并关联实际长辈。语音变更查看原话和拟写工单，授权员工确认或退回，处理后共同待办不再列出，凭证保留。这里还可查看巡查提醒、全员通知和权限申请。巡查周期和推送时刻由 Owner 设置。共有房间的咳嗽候选要有真实观察时段、覆盖分钟和个人归属依据，才可用于个人变化提示。[预警接口](integrations.md) · [巡查](rounds.md)

## 后勤、收费与报表

- **仓库管理。**「库存台账」新增品目时输入名称、计量单位，可填品牌、型号或包装规格。核对相似项，按业务选择复用或建立独立品目。入库、领用填写数量及相应经办信息；从「出入库流水」核对来源和结余。「护理用具工单」核实需求和责任人，办理后记录结果。
- **应收。**「费用管理 → 月度账单确认」核对最早待出账期，检查床位和护理价格、转床分段、请假、膳食和约定项目，确认生成账单。用「待收费 → 查看明细」看每项费用、抵扣、已缴和欠款；「医疗费用」可定位相关账目。「预缴余额」登记真实收款，用余额抵扣，实缴多出的金额转预缴。押金、预缴与应收分别核对。催缴跟进在「欠费提醒」记录，家属账务提醒以已授权的站内记录为准。
- **收款。** 线下登记选实际支付方式，录实收金额并确认凭证。渠道收款由财务输入金额，创建订单并出示微信或支付宝码，或使用已开通的扫码/终端渠道。核对签名回执和订单状态；仍待确认时查询原单。手续费由机构承担，明细分别列示实收、手续费、净入账。进入「收费记录／实收流水」「渠道对账」查看渠道流水号、到账日与核销。签约费率在收款手续费设置维护。
- **退款与退住。** 在「收费记录」选择原凭证，核对可退金额、原因、方式。可申请全额或部分原路退款，已退和处理中金额会影响本次可退额。「退款对账」查询原单并核实渠道结果；真实退款到账及线下退款按对应凭证处理，重复回执只入账一次。退住时在「退住结算」核对押金、预缴、未结账单和实际退款。查「日结报表」对照当日流水。[支付、退款与账单](finance-reports.md)
- **机构支出。** 在「财务总览 → 支出登记」人工登记已付金额、收款方、用途与凭证号，或按模板导入通用银行及河南电费 CSV，核对待匹配及重复行再确认。银行借贷方向、已缴状态和交易日期要与原件一致。网页支持文件对账；银企直联与电网实时取账有各自的授权前提。
- **民政补贴申报材料。** 选择申报月份、首次/续报和楼栋楼层，查看可申报长辈及缺失材料。按长辈维护证件或上传指定月份发票，有权限可设备料规则。勾选符合条件的行生成清单，核对材料版本并打印。正式机关受理凭证由经办人另核实。
- **统计报送、长期护理保险。**「统计报送 → 经营月报」按月份查看权限内收款、支出、工单和库存，点明细复核比较口径。「民政报送」生成草稿，纠正校验项，导出加密包，记录真正送出及接收回执；退回补正后保存新版。「长期护理保险 → 登记办理」选档案、统筹地区、经办阶段、文书编号和待遇期限，查看申请、评估、已核定待遇或复评的历史凭证。此处保管院内经办记录。[财务报送](finance-reports.md) · [长护险档案](dossier.md)

## 家属、员工与 Owner

## 备份、更新与故障处理

1. **留住本次业务版本。** Owner 从「机构设置 → 备份与恢复」查看定时、手工、恢复前与更新前时间点。当前实现按北京时间每日零点生成独立、压缩的加密全量快照；错过时段会在重新运行时保存当时状态。核实实际捕获时间、保留期、本机位置与各异地位置的校验结果。iCloud、115、百度等目标需要部署方配置可用的授权后端，未接入和失败会显示实际状态。
2. **迁移或查回。** 导出指定恢复点的 `.akbak`。导入时先上传、核验机构和摘要、检查版本差异，再登记快照库。应用到当前库是另一次确认，会先建立保护点。有已签认医疗、支付等冲突时，查看阻拦原因，必要时用离线密钥在独立目录恢复核查。机构库、离线解锁材料和平台运维凭据有不同的保管方式。[恢复演练](backups.md) · [存储边界](storage.md)
3. **升级。** Owner 在「平台更新」检查候选版本，下载并校验，核对发布说明后「备份并安装」。有签名发布源和托管启动器方可升级；可设自动更新时段。检查保护点和启动结果，失败时查回退记录。浏览器和 Electron 连接的是机构服务，原生壳的发行另行办理。[版本更新](updates.md)
4. **打不开、看不到、结果不明。** 本机访问失败先核对服务地址、监听端口和实时服务状态；远程设备核对机构对外地址。找不到菜单先查「个人中心 → 可用页面」和范围；被撤权则重新登录核对。提交后断网应先查原工单、账单、收款订单或最近改动；已创建的记录沿用原编号追查。模型或外部服务未开通时可继续办理相应的手工业务。

## 上线时逐项核验

持证医疗机构可通过部署设置 `NH_INSTITUTION_PROFILE=licensed-medical` 启用专项保全；清理和恢复演练前先核对本库实际模式。工作台业务验收使用独立的简体中文机构库（`zh-CN`）和虚构长辈资料，覆盖中文界面及通用业务能力。可在该库练习建档与试住、转床、评估、三餐与巡查、医嘱核对、来访排表、线下记账、档案回溯以及加密恢复。AI、短信、邮件、支付、云盘、更新签名源的实际可用性取决于部署与授权。设备目录中的米家、雷达、护理工牌及部分第三方交换端口提供接入约定，疑似跌倒/长期卧床从模拟事件到人工复核的院内流程可验证。物理设备联动、呼叫升级链、外部通知、HIS、政务送达、药库效期全流程、断网护理录入等应按当前交付版本分别验收。小程序和移动 App 另需真机、域名、签名及发布配置。[集成清单](integrations.md) · [商用验收清单](commercial-acceptance.md) · [客户端](clients.md)
