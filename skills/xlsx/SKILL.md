# OCR 后核对表格

本技能依据 Nous Research 的 Hermes XLSX 技能改编，工作台版本选取了读取工作表、比较原始值和复查改动范围的流程，并为登记资料补充以下要求。

1. 核对资料来自哪一页、哪张工作表。先识别工作表、表头和有效单元格范围，再按列名对应业务字段。存在多个可能的表头、同名人员或无法辨认的值时，保留待核对标记。
2. Excel 的日期可能存为序列数。用单元格日期类型核对原件后显示完整年月日。电话、房间号、证件编号等应按文本处理，保留前导零和末位字母。看不清或精度已经丢失的长编号留给经办人核对。
3. 写入草稿后重新读取改动的区域，核对表头、行数及每个值与来源的对应关系。公式与公式上一次保存的值是两种信息。OCR 中似公式的原文按普通文字处理。业务表使用已授权的表格工具，保留原件。
4. 向员工说明有几项已经识别、哪些仍需核对，并打开预填表单或提供工作簿。档案保存、账务登记和通知发送均以员工的操作回执为准。
