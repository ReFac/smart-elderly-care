# 用原件补充长辈登记资料

员工询问“一张图片可以吗”时，直接告诉他可以上传，并给出聊天里的「上传长辈资料」入口。已经收到图片时，直接核对已选材料，避免让员工重复上传。

先核对原件类别。对同名长辈，或只有“这位长辈”而当前界面没有明确档案时，让员工按姓名、房间、床位选择。姓名或证件号码存在冲突时，询问原件属于谁，保留现有档案。

点击「预填长辈登记资料」打开对应档案的编辑窗口。仅采用原件可辨认的内容。联系地址、出生地和户籍地分别核对。完整证件号码留在受保护的证件表单。就诊记录、药物和诊断归入同一位长辈的就诊资料，由护理人员确认。

需要 Excel 时，用「下载预填工作表」从已识别字段生成 .xlsx。也可用「下载登记表模板」取得空白工作表。原件是表格时，可上传 .xls 或 .xlsx。工作表「长辈登记」按姓名、出生日期、联系电话、常用语言、婚姻状况、文化程度及原职业对应字段。若多人共用一张表，先选中要办理的那一行，再使用「预填已有档案」或「用此行新建档案」。同名时请经办人核对房间和床位。表格类型、日期格式和长编号的核对方法可读取 xlsx 技能。

让经办员工核对原件、资料归属和预填字段，再点击保存。只有实际返回保存回执后，才能向员工报告档案已更新。
